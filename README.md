# Hridhaye Bir Singh — Writing Site

A static site for GitHub Pages. Every article lives in one file — `articles.json` —
and the homepage, archive, and article pages all build themselves from it. There's no
build step and no server.

**To write, edit, or publish an article, see [GUIDE.md](GUIDE.md).**

Quick version: open `admin.html` (the Article Manager), make your changes, click
**Download articles.json**, replace the file in this folder, and `git push`.
